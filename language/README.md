# Gametype scripting reference

Reference pages for the two scripting languages the game runs: Megalo (gametype scripts) and HaloScript (map and mission scripts). Each page lists the evidence level of its entries: V means the code was read, S means a call or label was read without the callee, H means inferred from use.

Engine functions are written as function_ followed by their address. Names that appear in the game data are given as the game spells them.
